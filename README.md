# StockFlow – Inventory and Sales Management System
## Project Overview
StockFlow is a web-based Inventory and Sales Management System designed for small retail businesses.
The application provides a centralized platform for managing products, product categories, inventory, customers, employees, and sales transactions.

## Project Objectives
- Develop a functional .NET Blazor web application.
- Implement secure user authentication.
- Implement Admin and Employee roles.
- Provide CRUD functionality.
- Automatically update inventory after successful sales.
- Prevent sales exceeding available inventory.
- Provide low-stock monitoring and sales history.
- Develop a responsive and accessible user interface.
- Test and deploy the application to a cloud service.

## Technology Stack
- C#
- .NET
- ASP.NET Core
- Blazor
- Entity Framework Core
- ASP.NET Core Identity
- SQL Database
- HTML and CSS
- Bootstrap (or equivalent)

- Trello

## Main Features
- User authentication and authorization
- Admin and Employee dashboards
- Product management
- Category management
- Inventory management
- Customer management
- Employee management
- Sales processing
- Automatic inventory updates
- Sales history
- Low-stock monitoring
- Basic reporting

## User Roles
1. Admin: Manages products, categories, inventory, employees, customers, sales, and reports.
2. Employee: Views products and inventory, manages customer information, and processes sales.
